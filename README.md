# 탈출회전 (Escape Rotation)

맵 전체가 플레이어를 중심으로 90도씩 회전하는 2D 퍼즐 플랫포머입니다.
게임인재원 1분기 팀 프로젝트로, Win32 API와 GDI 기반 자체 프레임워크 위에서 개발했습니다.

- **기술:** C++, Win32 API, GDI
- **역할:** 클라이언트 프로그래머 (회전 · 충돌 게임플레이)

## 담당 구현

- **실제 월드 좌표 회전:** 플레이어를 중심으로 오브젝트의 위치, 크기, 콜라이더 오프셋을 90도 단위로 변환
- **회전 입력 제한:** 공중이나 점프 중에는 회전 입력을 막음 (`CKeyMgr::SetKeyUnable`)
- **회전 방향별 스프라이트:** 현재 회전 상태에 맞는 스프라이트를 자동으로 선택
- **레버 · 레이저 연동:** 레버 하나로 여러 레이저를 켜고 끄는 1:N 구조, 레이저 충돌체를 동적으로 생성 · 삭제
- **AABB 충돌 밀어내기:** 겹친 깊이를 계산해 오브젝트를 밀어내는 처리

화면 회전 연출과 엔진 골격은 팀원이 담당했습니다.

## 빌드

Visual Studio에서 `Win32 Practice.sln`을 열고 x64로 빌드합니다. 실행에 필요한 리소스는 `Output/bin`에 있습니다.
